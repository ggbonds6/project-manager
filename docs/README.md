## 3. 文档维护约定（硬性）

1. **每次迭代必须同步**：`ITERATION.md`（总表 **+** 各迭代明细）、受影响的设计稿章节、相关 README 与本索引；
2. **一个主题一份权威文档**：发现重叠就合并；一次性计划完成后核减，**决策与实测数字进 ITERATION**，不要留在独立文档里；
3. **Markdown 表格两类禁忌**（曾把表格渲染打断）：
   - 表格中间**不能有空行**（空行即结束表格）；
   - 单元格内的竖线必须转义为 `\|`（例如 `` `local\|obs` ``）。
   两处已用脚本全仓体检并修复；
4. **不要写死机器相关路径**（除本机环境说明），不要写真实口令（一律走 `.env`/环境变量）；
5. 主系统与 AI 项目的文档**同时改**：AI 侧文档变更要回到本索引登记，反之亦然。
