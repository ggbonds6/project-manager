# 附件：上传限制 / 文件类型字典 / 在线预览能力

> 关联实现：上传白名单 `AttachmentController.UPLOADABLE_EXTS`；文件类型字典 Flyway `V5__file_type_dict.sql`（`FILE_TYPE`）；颜色组 `tagDict.ts` 的 `FILE_TYPE_TAGS`/`fileExtTag`；预览组件 `AttachmentPreviewModal.tsx`。

## 1. 在线预览支持矩阵（v1.6 现状）

| 格式 | 上传 | 预览 | 方案 |
| --- | --- | --- | --- |
| pdf | ✅ | ✅ 内嵌 | `<iframe>`，加载中显示等待态 |
| png/jpg/jpeg/gif/webp/bmp | ✅ | ✅ 内嵌 | `<img>`，onLoad 隐藏等待态 |
| txt / log / json / xml / html | ✅ | ✅ 原文 | 后端取文本展示 |
| **md** | ✅ | ✅ Markdown 渲染 | `react-markdown` |
| **docx** | ✅ | ✅ Word 渲染 | `docx-preview`（动态分包加载） |
| **xls / xlsx** | ✅ | ✅ 表格预览 | SheetJS(`xlsx`) 解析首个工作表 → HTML 表格（动态分包加载） |
| doc / ppt / pptx / 压缩包等 | ✅ | ⚠️ 视类型 | v1.7：OFD 用 `@sharp9/ofdjs` 首页 Canvas 试渲染；`.doc` 内容嗅探（实为 docx 走 docx-preview）；真·二进制 doc、ppt/pptx 等仍提示"暂不支持在线预览，请下载后查看" |
| 白名单之外的其他扩展名 | ❌ 拦截 | — | 后端 400 + 提示允许清单 |

> 组件内对解析类（docx/xlsx/md/text）均有加载等待态；解析失败给出"请下载后用本机软件打开"。

## 2. 文件类型字典 / 标签颜色 / 上传限制

- Flyway V5 预置 `FILE_TYPE` 字典 24 项（code=扩展名，name=中文名），与后端上传白名单一一对应；
- 颜色组全局维护于 `frontend/src/config/tagDict.ts`（PDF 红 / DOCX 蓝 / XLSX 绿 / OFD 紫 / 图片蓝 / 压缩包橙…），预览弹窗头部直接展示彩色类型标签；
- 后端上传强校验（`UPLOADABLE_EXTS`），**新增格式需三处同步**：后端白名单 + 迁移补字典行 + `tagDict` 加色。

## 3. 文件存储位置与预览加载（评估结论）

**现状/推荐：独立数据目录，不放在应用镜像/classpath 内**
- 本地默认 `backend/uploads`（可用 `UPLOAD_DIR` 指向任意磁盘/挂载点）；
- Docker 部署已挂独立卷 `pm_uploads`（`docker volume inspect pm_uploads` 可定位，便于备份/迁移），不入镜像、不随发布包覆盖；
- 访问链路：浏览器 →（Docker: nginx 反代）/ 直连后端 → `/api/attachments/{id}/download` 读文件流。

**两种方式的对比与结论**

| 方案 | 优点 | 不足 | 适用 |
| --- | --- | --- | --- |
| A. 数据目录/独立卷（本方案） | 实现简单、路径可控、易备份；内网吞吐足够 | 预览与后端共享带宽/磁盘 IO | 单机/内网、并发不高（本项目场景，推荐） |
| B. 独立文件服务器/对象存储+CDN | 上传/预览解耦、可水平扩展、大文件友好 | 需额外中间件/密钥/配置 | 公网高并发、海量附件时再引入 |

**对预览加载的影响与处理**
- 预览本质上仍是"后端把文件流吐给浏览器 + 前端解析"，差异只在带宽/IO 位置；内网规模下 A 与 B 对单文件加载差异不明显；
- 已实现的加载体验：图片/pdf 使用 `onLoad` 等待态、docx/xlsx/md/文本解析时显示 Spin；这样即使文件较大，用户也能看到"正在加载"，而不是白屏；
- 若未来接入对象存储/CDN，前端仅需替换 `attachmentUrl` 的地址前缀，组件无需改动；届时可视需要补更细的进度条（当前等待态已可接受）。

**服务器部署约定**：附件目录独立挂载（Docker `pm_uploads` 卷/裸机自定义磁盘路径），纳入每日备份；不存放在项目源码/镜像内。详见 `deploy/README.md`。

## 4. 已集成开源组件

- `docx-preview`（Word docx → HTML，动态 import 分包）
- `xlsx` SheetJS（Excel xls/xlsx → 表格 HTML，动态 import 分包）
- `react-markdown`（md 渲染）
- pdf/图片由浏览器原生内嵌

**试集成（v1.7，效果待评估）**：`.ofd` 用 `@sharp9/ofdjs`（首页 Canvas，jszip 注入全局）；`.doc` 内容嗅探（zip 头 → docx-preview，真 97-2003 二进制 doc 提示下载）。**仍不集成（当前无稳定纯前端方案）**：`ppt/pptx` → 统一提示"暂不支持在线预览，请下载后查看"；后续若业务确需，可评估服务端 LibreOffice 转 PDF 或国产 OFD 渲染组件的投入产出。
